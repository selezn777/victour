# ВикТур (VicTour)

Пространство проекта для сайта премиального private-туроператора по Вьетнаму.
Бриф: `docs/VicTour_tours-and-prices.md`.

## Структура

- `docs/` — исходный бриф (программы, цены, экономика, требования к сайту).
- `reference-repos/` — склонированные open-source репозитории для дизайна/реализации (не часть будущего кода приложения, только референс).

## Референс-репозитории

| Репозиторий | Зачем |
|---|---|
| `Online-Booking-Management` (Chisfis) | Каркас booking-сайта: Next.js 13 + Tailwind, 30+ страниц, календари, хедер с темой/бургер-меню — ближе всего к структуре брифа |
| `nextjs-hotel` | Полноэкранный герой с фото/видео салона, стильные футеры |
| `luxury-hotel-website` | Премиальная визуальная эстетика без "дешёвого люкса" |
| `cal.diy` | Cal.com community edition — календарь доступности гида, защита от двойного бронирования |
| `react-booking-calendar` (demark-pro) | Лёгкий компонент календаря с overbooking protection, диапазон дат (для Далата — 2 дня) |
| `reactjs-availability-calendar` | Облегчённая альтернатива cal.diy для MVP |
| `awesome-shadcn-ui` | Каталог лучших shadcn-ресурсов и компонентов |
| `ecommerce-shadcn-nextjs-template` | Паттерны карточка → страница тура → корзина (для пакетного конструктора 2–4 тура) |
| `react-currency-hooks` | Хук конвертации валют (USD/VND/RUB с фиксированным курсом) |
| `currency-exchange-widget` | TS-виджет конвертации для хедера |
| `react-whatsapp-floating-button` | Плавающая кнопка WhatsApp с конфигурируемым номером |
| `react-whatsapp-widget` | Виджет чата с предзаполненным сообщением (тур/дата/гости) |
| `travel-landing-page` | Дизайн-референс лендинга travel-агентства |
